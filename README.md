# Breast Cancer Classification Using Classical and Quantum Machine Learning Algorithms

## Overview

This project presents a comparative analysis of Classical Machine Learning and Quantum Machine Learning algorithms for breast cancer classification. The objective is to evaluate the effectiveness of quantum approaches against traditional machine learning techniques using the same dataset and preprocessing pipeline.

## Algorithms Implemented

### Classical Machine Learning
- Support Vector Machine (SVM)
- Random Forest (RF)
- Convolutional Neural Network (CNN)

### Quantum Machine Learning
- Quantum Support Vector Machine (QSVM)
- Quantum Random Forest (QRF)
- Quantum Neural Network (QNN)

## Dataset

The Breast Cancer Wisconsin Dataset is used for training and evaluation. The dataset contains diagnostic features computed from digitized images of breast mass cell nuclei.

## Data Preprocessing

The following preprocessing steps were applied:

- Data cleaning
- Label encoding
- Feature scaling using StandardScaler
- Dimensionality reduction using PCA
- Train-test split

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Objective

The goal of this project is to compare the performance of classical and quantum machine learning algorithms for medical diagnosis and investigate the potential advantages of quantum computing in healthcare applications.
